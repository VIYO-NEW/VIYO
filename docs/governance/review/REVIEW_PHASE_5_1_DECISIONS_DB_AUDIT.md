### Finding 3

Lock 21's `Does NOT apply to` text uses neither axis — it distinguishes by content type ("observations of state, not governance"), not by file path or canonical-status classification.

The audit cannot consistently apply both classifications. Whichever resolution the Arbiter selects, one of the audit's findings must flip.
- SEVERITY: Yellow

### Finding 4

- FINDING: The parenthetical descriptor "23 distinct page IDs" is internally inconsistent with the audit's arithmetic. The enumerated list has 23 distinct title-IDs (D57 through D84 with gaps). Per §1.4 Anomaly 1, D67 has 2 distinct page IDs and D68 has 2 distinct page IDs — i.e., 4 page IDs for 2 nominal IDs. Page-ID total: 21 (single-page title-IDs) + 4 (D67 + D68 page IDs) = **25 page IDs**, not 23. §1.3's own closing sentence confirms 25: *"Treating the duplicate page IDs as separate physical records: 54 + 25 = **79 physical records**."* The leading parenthetical should read "23 distinct nominal Decision IDs" (or "23 distinct title-IDs"), not "23 distinct page IDs."
- REASONING: Internal arithmetic inconsistency in the deliverable's own data. The conclusion (79 physical records) is correct; the descriptor in the introducing parenthetical is mislabeled. Per deliverable's declared structure (audit reports verifiable observations), descriptor labels must match the arithmetic they describe.
- SEVERITY: Green
